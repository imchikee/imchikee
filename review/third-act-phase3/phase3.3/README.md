## 当前落点

负责轻触的是杯把右侧最宽的粉色趾垫。Phase 3.2 接触帧中，它的暗色描边和阴影叠到键帽后侧的暗缝。标注的最近键帽，其浅色顶面仍清楚露出。画面能读出爪子下落和靠近键缘，未形成趾垫压住可见键帽顶面的视觉证据。

以第 28 帧中 `x=730` 为纵向截线。图上粉色下缘为 `y=921`，可见暗色交界约为 `y=927–928`，浅色键帽顶面取 `y=931` 为统一采样参考。粉色下缘到这个参考点相差 **10 个原图像素**。暗边与暗缝在画面中有投影交叠，二维合成图无法量出遮挡区域的物理间距。

| 姿势 | `x=730` 的粉色下缘 y | 相距亮顶面参考点 |
| --- | ---: | ---: |
| P0 | 904 | 27 px |
| Rebound / 落爪 | 914 | 17 px |
| Phase 3 Contact | 917 | 14 px |
| Phase 3.2 Contact | 921 | 10 px |

两张图均用原图 `(663, 850, 845, 981)` 裁框，坐标从 0 起、右下边界不含。原像素对照按 3× 最近邻放大，标注图按 5× 放大。粉色下缘取 `y=880–928` 内最靠下且符合 `R >= 182`、`R−G > 65`、`3 < G−B < 58`、`G < 151` 的像素。键帽顶面及键盘区前缘沿可见笔触手工描边。

在 534 px 宽时，Phase 3 到 Phase 3.2 的 4 px 下压只约 1.5 个显示像素。最明显的接触变化集中在深色描边和阴影交界，浅色顶面的轮廓没有可辨的随动或下沉。这个机位仍能看到部分键帽顶面，是否能在结构自然的前提下压到其中一个，留待静态姿势验收。

## 播放器

下载分支文件后在浏览器打开验收目录的 `index.html`。GitHub 的 HTML 文件页供查看源码。画面宽 534 px，打开「放大趾垫与键帽」可同时查看同帧局部。拖动、逐帧和关键阶段跳转会暂停在选中帧。播放会循环，速度可选 0.25×、0.5×、0.75× 和 1×。

| 帧（从 0 计数） | 姿势 |
| --- | --- |
| 0–23 | P0 |
| 24–27 | 落爪 |
| 28–33 | 接触 |
| 34–37 | 回弹 |
| 38–116 | P0 |

母版逐帧解码核对全部 117 帧，每帧持续 1/30 秒。原 `p0.png` 和 `rebound.png` 与母版相应合成帧 RGB 一致。接触图直接保存母版第 28 帧的完整 RGB，逐像素匹配第 28–33 帧。

本地 Chrome 实测了 534 px 全图、同步放大、鼠标拖动、暂停、前后逐帧、五个跳转和四档速度。1× 播放依序经过五段，在约 3.91 秒回到起始帧并继续循环。
