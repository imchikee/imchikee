## 基线与预览的范围

baseline/ 中的 README 原样复制自本仓库保存的 [homepage-before.md](../../homepage-before.md)，横幅、动态介绍及两张卡片复用 toolbox-labels 中未改动的原素材，技术图标用原样式而非其标签候选。基线 README 的二级标题与加粗在本地转换成 HTML；新 README 直接使用可用于 README 的 HTML，无额外 Markdown 依赖。

两版共用同一近似 GitHub 外框及正文样式。baseline/ 是已存版本的本地重建，**不是本轮重新打开 GitHub 的实时截图**。动态数据也沿用已存 SVG，没有更新贡献记录。预览外框的 CSS 与比较页的 JavaScript 不属于待部署的 README；候选正文只用图片、picture、段落、标题和链接等既有布局方式。

手机横幅采用独立构图；两张卡片是独立图片，窄屏依靠自然换行堆叠，没有固定的两列表格。关键信息有 alt、自述或真实文字链接。装饰标签和图片脚注仍较小，是否接受其视觉密度需用户看实际效果。

## 已验证的内容与限制

- 用本机已有 Chromium 实际截图并查看深浅主题和手机效果，未安装 Python、Node 或浏览器依赖。
- 浏览器检查 375、430、768、1024、1280、1440px 宽度：未发现页面横向溢出或缺失图片；430px 下两卡上下排列，选择手机横幅；深色主题选择原有深色贡献蛇素材。
- SVG XML 全部解析通过；用浏览器测量新横幅及卡片文字边界，未发现越出 SVG 画布的文字。
- 两张相隔 1.8 秒的横幅截图不同，确认动态在该浏览器中实际运行；不据此声称所有动画在所有浏览器上表现相同。
- 对照页的主题与中段切换已检查。常规截图在素材和字体就绪后约 2.8 秒取得，让现版轮播和新稿文字有时间展开；截图仍仅记录某一帧。
- 浏览器阻止 HTTP/HTTPS 资源请求，全程读取本地文件；没有调用 GitHub 渲染接口或向外部上传草稿。尚未验证 GitHub 线上对 HTML / SVG 的最终呈现。

重建时使用：

```sh
python research/github-profile/drafts/current-evolution/build.py
node research/github-profile/drafts/current-evolution/capture.mjs
```

build.py 仅依赖 Python 标准库，素材来源使用仓库内相对路径。capture.mjs 使用 Node 内置模块和 `/opt/google/chrome/chrome`；不同设备可通过 `PROFILE_CHROME` 指定本机 Chromium 可执行文件路径。浏览器使用独立临时配置并在结束后清理，受限环境可能需要允许本地浏览器进程启动。
