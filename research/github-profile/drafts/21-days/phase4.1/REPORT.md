## 原画结构与遮挡

使用 [1254 × 1254 原始九格](../../../cpp-humor/storyboards/21-days/hamster-storyboard-v1.png) 的 `viewBox="21 446 384 350"`。输出沿用 `xMidYMin slice`，按宽度等比放大，横向居中，顶部对齐，底部裁去约 1.24 个源像素。标题和画面同属原画。

| 原画位置 | 角色与动作依据 |
| --- | --- |
| 左侧 | 戴眼镜的成年同伴。棕色前臂横过身体和主角左侧橘毛边，原画已经画出食指指向电脑。杯子、桌边纸本及电脑底座在它前面，适合先收再抬指。 |
| 中间 | 戴绿色卡车帽的主角。笔记本背盖遮住胸口和大部分前爪。原画脸近正面，回应依靠视线和一次短眨眼。帽子、脸部轮廓、腮部、嘴鼻及胡须沿用原像素。 |
| 右侧 | 眯眼微笑的成年同伴。前爪原本靠着笔记本右缘，肘部被蓝色书堆遮住，纸页的两侧分别被电脑和书堆遮住。抬起已有的纸页并在其边缘保留握持关系。 |

## 动作与实现

| 时间 | 动作 |
| --- | --- |
| 0.00–0.40 s | 保持原始分镜。三只仓鼠围着同一台电脑，原画食指和朝向完整保留。 |
| 0.40–1.80 s | 左侧同伴先收爪，再朝屏幕方向伸出食指。1.53 s 接近指屏峰值。 |
| 1.37–2.43 s | 主角将视线移向左侧同伴，约 2.00 s 下移并短眨眼回应。左爪随后回到原画位置。 |
| 2.30–3.77 s | 右侧同伴抬起已有的笔记纸，主角向右下看纸。纸页略停后回落，原有书堆仍遮住右肩和部分前爪。 |
| 3.80–4.20 s | 三只回到共同工作姿势，接到下一轮同一静止画面。 |

原画是扁平图，左右前肢离开原位后需要补足背后的毛面和桌面，纸页也需要补齐被遮挡的边角。局部补画使用同一分镜里的原画取样及手工轮廓。前臂和手爪作为连续的完整姿势做刚性旋转和平移，从源像素保留毛纹和爪形。肩根在身体内过渡，杯子、笔记本和书堆按原始前后关系遮挡动作层。眼睛使用原画眼部像素做小幅移视，闭眼只重建眼睑区域。背景、桌面和道具的画面坐标固定。现有原画可以支撑这组动作，因此这次采用局部补画。

[build.py](build.py) 负责原生姿势合成、取景、导出和九宫格。与既有原型一样，使用 Pillow 处理原画局部，由 FFmpeg 导出。复现命令为在本目录运行 `python build.py`。

## 实际检查

- 在 534 × 485 下实看关键姿势和中间帧。绿帽主角始终可识别，左侧先收再指的动作读得最清楚。中央短眨眼和移眼回应，右侧纸页从书堆与电脑之间抬起后回落。
- 放大检查肩根、爪尖、纸边、书堆和电脑边缘。初版左肩暗线与纸页下方的采样痕迹已修正。成片中右爪和纸页仍有一部分被原画道具遮住，所以奉纸比指屏低调。
- 第 0 帧与第 125 帧的原生裁区 RGB 均和原图逐像素一致。第 114–125 帧保持原姿势，回到下一轮没有画面跳变。
- 本地 Chrome 在 534 × 485 下连续播放 APNG 两轮以上，并播放 MP4 至结束。APNG 有 126 帧，每帧的延迟字段精确为 1/30 秒，循环标记为无限。126 帧全部解码并逐帧匹配无损导出前的 RGB 图像。MP4 为 126 帧、30 fps、4.200 秒。
