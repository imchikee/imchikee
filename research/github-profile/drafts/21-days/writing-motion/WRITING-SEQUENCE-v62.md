# 多笔画书写动作 v62

用户指出 v61 动作相当于在纸上划一道。固定预览现更新为 6.5 秒 i++; 书写：八段落笔，笔画间抬笔换位，最后抬起并停顿。字形沿纸面两个方向投影，朝向仓鼠。不是仅扩大上一版单弧线。

沿用 v60 姿态与 v61 局部前肢，不再生成静态新角色。笔尖由笔画路径驱动，固定根部和握笔中心通过两段定长几何求转角；爪笔刚性同步，毛茸茸的前肢以宽范围网格过渡。纸面固定，字迹只在落笔时增长。先前窄过渡区在大幅度下产生折角，已扩大过渡范围；按纸面比例缩小字间横向距离，减少过高抬腕。

实际查看六个关键画面（起始、中间、换位、后半、收笔、停顿）。对全时段按 0.02 秒采样，根点位移为 0，爪笔长度误差约 3.1e-13 px，笔尖目标跟踪误差约 2.5e-13 px。播放/重播控件通过。仍是动作草图，不代表用户认可或完成精绘/场景/最终循环。没有改第一幕及线上资产。

旧单笔动作保存为 sketch-motion-single-stroke.js。当前源码 sketch-motion.js；截图和验证沿用 render-sketch-motion.mjs。
