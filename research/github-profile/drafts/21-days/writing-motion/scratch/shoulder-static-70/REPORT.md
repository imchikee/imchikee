## 合成关系与接缝来源

见 [图层拆解](layer-breakdown.png)，局部原场景范围 (320,730,330,250)，统一放大 200%；灰色为透明层的显示背景。

1. `base` 先画 scene-soft-master，再用 scene-soft-clean 修去旧臂/笔。此补底本来有 18 px 模糊遮罩，本轮不改。
2. `headSource` 先画 v23 完整头部，再叠 v26 chestLayer（原有 4 px 遮罩过渡）；经完整头部遮罩（原有 5 px）叠进 base。拆图 02/03/04/05 分别展示这些阶段。去臂后的胸毛覆盖到了之后前臂要出现的位置。
3. `armWorld` 从 v33 原画按 (+5,+4) 注册，按既有 armPath 裁切，且只保留 x<515；其右为刚性 gripWorld。裁切遮罩原有 0.7 px 模糊，非自然腮毛遮挡。拆图 06 可见上边为较直的斜切线。
4. `shoulderCover` 从上述 base 复制，不是独立肩毛素材；遮罩约 x=325–414，随后 base 才画书页与内容。最终顺序为 base（含头/胸/书页）→新增字迹→活动前臂及手爪/笔→shoulderCover。

**主要可见斜缝来自 armWorld 的上缘裁切覆盖到另一份胸毛上**：约从 (410,807) 延至 (515,835)。既有 armPath 以 Q(472,823)(525,838) 连出这段边，未保留 v33 原画中腮毛压住前臂的细碎过渡和阴影。shoulderCover 只遮住最左根部，不能覆盖右侧长斜缝。拆图中的 raw v33 原画有自然遮挡，而 baseline 和 without-cover 都保留长斜缝；因此不能把问题仅归于最后一层 shoulderCover。去掉该层只会更暴露左根，并不修好接合。

## 唯一静态候选与视觉判定

[静态前后对照](comparison-0.png)，[候选](candidate-0.png)，[局部修复层](repair-layer.png)。

从同一份已注册 v33 原画提取肩根/腮下过渡，沿局部多边形直接覆盖，尝试恢复被裁掉的原有过渡。范围仅 x≈376–513、y≈791–857；没有模糊、羽化、调色、缩放、重画前肢轮廓或改变 armPath，所有运动及笔迹计算沿用原 70% 源码。

**未通过成功标准。** 右图肩上缘局部的过渡有所变化，但左根新增暗弧，靠右在约 (509,825)–(513,839) 出现明显阶梯切口；上缘还可辨补片边界。原画的腮、臂和当前 base 不是可用一个局部硬裁块无缝拼合的同一分层素材。不能据“用了原画”就认为连接自然。没有扩大补片或继续试第二种修复，也未用羽化掩盖。

现有 v26 去臂胸毛可用作身体底图，v33 有自然腮—臂关系；**缺少的是与当前 base 注册一致、能单独覆盖在活动臂上的前景肩/腮毛层及其真实毛边遮罩**。本次仅凭现有素材局部裁贴未得到合格连接，不证明所有静态修复方法都无效。
