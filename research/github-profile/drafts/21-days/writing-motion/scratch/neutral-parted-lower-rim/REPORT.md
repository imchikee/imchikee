# 第二幕 · 中性微张口下缘修订

**单次候选通过视觉自查，等待人工验收。** 粉红半圆唇线消失，口腔底部以浅暖褐阴影过渡到奶油色下巴毛发。表情比原版更自然、更安静。

先看 [534px 场景等效对照](review-display-534.jpg)。两版独立头部统一缩至约 21.9%，对应第二幕基准画面约 67px 的双眼中心距。修订后不再有醒目的粉红弧边，两颗门牙仍清楚可见，小开口仍能读出，但比原版更含蓄。正常尺寸很难单独分辨牙尖间隙。

再看 [同倍率鼻口放大](review-mouth.jpg)。牙齿的长度、厚度和上端连接与原版接近，牙尖下方保留窄暗隙，与较亮的下巴毛发分开。下缘靠短毛和柔和阴影消散，原有均匀半圆消失，也未见新的深色 U 形线或外扩上翘的嘴角。

[同倍率完整头部](review-head.jpg) 中，眼睛的形状、大小和高光，鼻子的形状与位置，以及圆腮、帽子、耳朵和头部透视在视觉上与基准相符。全图生成导致帽料与毛发细笔触有轻微变化，原像素并非完全一致。毛流从上口鼻到下巴连续，未见生硬接边。
