# 第二幕 · 完整头姿结构验证

**静态自查未通过，不进入精修或眨眼接入。** 534px 并排能读出更低的头和偏下的双眼，短笑、门牙和宽腮仍可辨认。接在第一幕 3.179s 之后，注视仍不足以在第一眼明确落在笔尖旁字行。眼睛虽然维持圆润开口，但虹膜发散纹过于明显，削弱了原有的柔和圆亮感。[534px 对照](review-534.png) · [切换对照](review-cut-534.png)

这一张使用单视图头部深度代理统一转动帽檐、额头、鼻口和腮帮，再在投影后的眼窝内独立构造两只球面眼，左眼向下，右眼较多朝左下。代理设定为前俯 15°、向画面左转 4°，是试作参数，并非从原画测得的角度。保留现有眼口的圆润比例，未用眯眼模拟低头。第一幕用于姿态参考。新眼球有独立结构，但帽子、耳根与面部仍复用原画的单视图表面，并未获得完整的新遮挡关系。

原尺寸可见原帽钮和新位置帽钮叠在一起，帽冠上缘亦有重影。在锁定背景的前提下，候选的单视图代理没有覆盖好帽顶退让后应显露的那一小片背景。远眼未见明显被拉成斜长形，腮肩连接与握笔关系仍在，但帽顶重影已触发停止条件。[头部原尺寸](review-head.png)
