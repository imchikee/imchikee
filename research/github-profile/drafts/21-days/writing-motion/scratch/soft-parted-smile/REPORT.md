## 五项验收

1. **534px下门牙是否清楚自然？只部分改善。** 比闭合版增加了露牙量，全景能感觉嘴部多了一点立体感；但两颗牙仍很细小，清楚辨认各自长度主要依靠放大，不能把正常尺寸的效果说成充分达到要求。
2. **是否更有立体感和灵气？放大结构有进步，整体不能通过。** 新牙有长度、圆头和明暗，不再只有微露白点；牙根后方的小暗部增加深度，没有恢复原始宽大U形张口。但正常全景变化较克制，且嘴周贴片破坏了自然性。
3. **是否避免牙尖顶下唇？未见原来的托牙深色下唇结构。** 两牙从上口鼻下方露出，牙后是浅暗部，没有围住牙尖的U形深色下弧。仍然不能用这一局部结构改善抵消材质失败。
4. **嘴角是否自然、无钩状或机械对称？钩状上扬没有恢复，机械对称只部分减轻。** 上口鼻有一点体积差异，但左右弧线仍相近，不能夸成完全自然生动的最终表演。
5. **眼睛、鼻子、圆腮及其他原画是否不变？嘴部范围之外是原像素。** 鼻子、双眼、帽子、脸型外轮廓、身体、笔爪、书页和场景均保留闭合版；然而新嘴周毛纹和色温不匹配，产生清楚的暖色椭圆状接边。这是本轮明确失败点，不宣布“角色美术全部保持”。

编辑输入为闭合版(620,690)–(760,790)的140×100[裁框](mouth-reference.png)。原始U形版本仅裁出[牙体参考](tooth-volume-reference.png)，没有采用其张口轮廓或拷贝旧牙像素。新嘴是一次完整绘画，不是门牙纵向拉伸。

按原坐标一次注册回闭合底图，仅取嘴部与极窄连接范围，鼻子仍使用原图。没有几何变形、原始/闭合嘴图像混合、重新排版或小范围反复覆盖。完成后先查看534px单独全景及三方全景，再查看同倍率嘴部和边界。看到贴片后停止，没有进行第二轮修补。
