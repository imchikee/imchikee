## 新缺陷与保留风险

**最重要的新偏移是目光与情绪。** 现版偏低头看笔记；新候选更像抬眼朝观众微笑，嘴也更张开。虽然画风更接近第一幕，“专注伏案”的程度下降。不能因为统一性改善就说学习姿态也全面优于现版。本轮不追加眼睛或嘴部修补，交由用户判断这一完整候选。

左灯、木桌、C++杯、书架、参考书、笔记本和标题均保留其场景位置及内容身份；但生成工具也轻微重绘了环境笔触、书脊与色彩，**并非背景逐像素不变**。没有观察到新的明显拼贴接缝、重影、断爪或书本结构破损，也没有将旧背景硬贴回来。原画尺度下仍可见生成纹理的规律感。

## 代码恢复与实际检查

角色与画风主要参考 `reading-motion/lighting/front-v1.png` 和 `down-v2.png`；第二幕场景参考 `more-cpp-finish/scene-final.png`。完整全景对照的第一幕使用现有实际输出 `more-cpp-finish/reading-start.png`，局部使用第一幕1316×1195原画，避免把低分辨率放大误判成绘画笔触。

实际查看了原始生成图、恢复排版后的完整图、534px单独显示图及全部局部对照：未见双重字迹、文字压到粉爪/笔杆或明显超出纸面；纸面代码保持朝仓鼠。原始生成图到候选的差异仅在纸页墨迹范围（x=51–1314、y=864–1118），不是角色后加工；此范围检查只证明修改范围，审美结论来自实际画面。
