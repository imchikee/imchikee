# 第二轮：右版2.581秒独立轮廓实验

**结论：实验未通过视觉验收条件。** 已摆脱旧轮廓内换纹理的限制，确实建立并显示了新外形；但目前的圆肘仍过宽、肩接入生硬，尚不能构成可信的仓鼠前肢。candidate.png 是纯色诊断轮廓草案，不是绘本插画修复成品。没有接入正式预览。

## 实际方法

1. capture.mjs 加载现有 motion-comparison-after.html，只调用真实 sketchMotion.render(2.581) 并等待两帧，输出 baseline.png。未研究已否定的左版，也没有处理其他时刻。
2. 为取得与当前角色注册一致的无前肢底层，读取 scene-motion-study.js，并在浏览器内存中的第二个实例暴露已有 base、shoulderCover。未写回源文件，未调整原有运动算法。base 本身已用 scene-soft-clean、head-chest-clean-v26、原头层和纸页层补底。导出 clean-base.png，实看可见活动前肢和笔已消失，身体胸毛及纸页底层存在。
3. 比较实际基准与无前肢底层，限定在旧肢体周围，排除原手爪/笔保护区，提取发生变化的旧前肢像素；用底层替换这些像素。不是把新肢体直接盖在旧肢体上。cleared-limb.png 和 old-limb-mask.png 提供清除证据。原笔迹留在基准，不从底层整体覆盖纸页。
4. compose.html 定义唯一一个新的独立 Bézier 外轮廓：肩下接出，肘部向左下展开，再从下方向握笔爪后面回收；上缘、下缘分别有控制点。轮廓不使用旧位移公式，也不继承上一轮的提取 Path2D。
5. 新轮廓以独立透明白色遮罩输出 silhouette-mask.png，纯色诊断着色。沿原腮毛边界做遮挡保护，避免轮廓盖上脸部。新轮廓延伸到手爪后方，不在 x=490.700015 处截断。
6. 从基准按曲线手工描出的粉爪形状和铅笔轮廓取原像素，最后覆盖。笔边缘加保护余量，并将保护区的抗锯齿像素原样还原；没有移动手爪、手指、笔或旋转握姿。这里的手工描边存在精度限制，见下。

## 轮廓与遮挡证据

- contour-overlay.png：青色是从基准/无肢体底层差异提取的旧可见前肢区域，粉色是新完整 Alpha Mask；重合为混色。旧区域排除了手爪和笔，因此不是包含手爪的整条肢体外框。
- 新肘部明显伸出原前肢左下侧，下缘覆盖书页左上方的一小部分，这是新前肢的遮挡，书页内容本身未重绘。上缘让原腮毛在前，腕端让原粉爪在前。
- 辅助像素计数：新遮罩在旧提取区外有5876个像素，其中4218个在最终图中实际产生变化。不能将这些计数当作自然度证据。
- 旧区中露在新遮罩外的1423个像素已恢复为底层，无检测到仍与底层不同的像素。实看 cleared-limb.png，未见一条完整旧前臂残影；粉爪周围仍有少量橙色描边，不能宣称边缘提取完全干净。
- 已定义手爪/笔保护区内部像素改变为0；变化在局部实验包围范围之外为0。范围检查只用于排查意外写入，不能证明所有解剖或遮罩边界正确。头部、眼神、帽子、背景和纸页外部保持基准；新轮廓遮住的纸页区域例外属于允许的肢体遮挡。

## 限制与失败原因

固定肩参考与手爪使屏幕中的端点距离不变，不能仅靠外扩轮廓证明真实前肢长度得到恢复。当前轮廓选择向下扩肘来容纳体积，结果更像宽块，未建立可信的前后折叠。现有素材没有独立的粉爪/手指精确 Alpha，也没有该姿态被遮挡的肘部结构参考，手工取层仍有边缘问题。

不能据本实验断言固定端点彼此矛盾或必然无解。失败发生在本轮选定的轮廓与遮挡设计，证据不足以宣布修复成功。此次只做这一条轮廓，没有继续精修毛发、优化旧形变或实现连续动画。
