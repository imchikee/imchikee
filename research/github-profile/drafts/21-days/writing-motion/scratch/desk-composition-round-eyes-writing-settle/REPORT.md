# 第二幕前肢过渡与收笔修订

基于 [70aeefc 的短书写候选](../desk-composition-round-eyes-writing/REPORT.md)，沿用两幅已绘制的前肢姿势。在 0.617–1.517s，前臂相对两侧按成对节点响应腕部高度，肘外侧使用一条插值轮廓，毛束细节与低频光影分开过渡，腮下接触阴影以起笔画为基准。手腕与铅笔仍由原画中的同一刚性层承载。

收笔从 2.26s 起逐渐抬笔，约 2.57s 到达最高点，然后缓落，至 3.02s 停在原候选的最终位置。书写段接触轨迹、抬笔移位和逐帧字迹数据与 70aeefc 相同。

Chrome 实际以 534px 播放两个 MP4 至结束，第二幕采样 15 个中段和收笔时点。压缩前的 192 帧上，两眼区域与 70aeefc 的 RGB 逐帧相同。联播前 192 帧解码一致，后 192 帧与独立第二幕一致。两段 MP4 为 60fps，GIF 为 25fps、80 帧。

原像素下，肘下缘靠纸面的位置仍有少量柔边，靠近腕部的毛束在较大位移时仍可看出过渡。候选待人工播放验收。

使用 `bash export.sh` 可重做视频、GIF 和连续姿势图。输入画采用相邻 scratch 中的原资产。
