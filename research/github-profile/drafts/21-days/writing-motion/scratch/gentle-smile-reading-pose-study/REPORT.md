# 第二幕 · 向下注视结构草模

**这张草模未达到精修门槛。** 在 534px 全图里，暗瞳略低，右眼也有向左下收的趋势，但第一眼仍不像在看笔尖旁的字行。软化虹膜分界后，上一轮的硬套圈感减轻。同时两眼变得偏暗、平，少了原版圆亮的神态。放大能辨认两眼不同的方向，正常尺寸下仍读不出共同注视点。[534px 全图](review-534.png) · [眼部放大](review-eyes.png)

草模在两处开眼内部重画连续暖棕明暗和柔边暗瞳，各保留一枚上方反光，范围外像素与原图一致。上睑沿用基线。极小下压主要会减少开口上方的可见面积，这张草模呈现的主要问题仍是方向提示不够清楚，且眼睛已经略失神。上睑没有单独试做，本轮没有画面证据支持靠它获得自然阅读感。

基线为 `5e19f08b144caf0f50a414c9dc8487f1293d5efe`。[完整草模](pose-study.png) 保留供人工验收。
