# 前景腮毛独立绘画模板

基准 commit：989af770a43072243c0d7937b87605394524c0a0。此目录只准备制作与验收工作流，**尚无新毛发，接缝仍未解决**。未调用 imagegen、未抠图、未改正式动画或既有素材。

## 打开与绘制

在 Krita / GIMP 中打开 **painting-template.ora**（OpenRaster）。画布 1316×1195，左上角为 (0,0)。三层从上到下为：

1. `PAINT HERE`：全透明 RGBA，在此独立画新毛发；没有复制任何旧臂、笔、书页或旧臂投影。
2. `GUIDES ONLY`：默认隐藏，可打开查看青框和原斜缝；只作标注，不是遮罩。导出前隐藏。
3. `REFERENCE ONLY`：当前 70% 实验真实 t=0 全图，默认可见。请手动锁定以免误画，导出前隐藏。

也可新建同尺寸文档，导入 reference-0.png 作参考，再把 foreground-cheek-template.png 作为空白绘画层。**不要以155×80局部画布代替全图，不要裁透明边、缩放、居中或移动图层。**

- [原坐标参考](reference-0.png)：1316×1195，未经标注；原70%渲染器逐通道比较差异为0。
- [补绘框与斜缝标记](reference-marked.png)：同尺寸。青框 x=375–530、y=775–855；黄色标的是原有裁切接缝，不是新毛发轮廓。
- [局部绘画指引](painting-guide.png)：场景 (350,745,250,180) 放大400%，仅供观察，不要作为导出素材。
- [空白前景模板](foreground-cheek-template.png)：1316×1195 RGBA，1,572,620个像素的Alpha均为0。

## 还需要人工画什么

只画左腮下沿从身体前方垂下、覆盖活动臂上缘的**新前景毛束**：上部与当前头胸的毛向、颜色、亮度连续，下部以真实细毛和局部半透明毛尖过渡到空气。不要把框填成一块不透明补丁，也不要沿黄色线画出另一条硬边。

- **A 接合区**：框内上方的腮毛内部，新画的毛束从这里接出。可观察参考取色，但不要复制一块含旧臂的扁平图，不要涂大面积模糊或灰影。
- **B 毛尖区**：原斜缝附近、前臂上方，是前景腮毛遮住后方活动臂的交叠带。毛尖需要不规则的真实Alpha，不把旧臂的橙色纹理和臂上暗影带入前景。
- **C 必须透明**：框外、其余身体/背景、活动前臂、手爪、笔、纸页以及投在旧臂上的阴影。框内也不能整块填满；右上红框提醒t=0笔杆所在位置，它不是全段扫掠范围或自动抠图遮罩。未来验收需继续检查笔移动时是否被不当遮住。

参考层含这些物体是为了定位；它们绝不能进入最终前景PNG。画完后隐藏参考/指引，只导出绘画层为带透明通道的 **foreground-cheek.png**，尺寸仍为1316×1195。保留工作文档，便于改毛尖。

## 同一层的静态/动态验收

打开 [index.html](index.html)，用“加载绘制后的PNG”选本地文件；不需要上传或写入其他应用。预览可从本地file打开，若浏览器限制本地图片读取，可从仓库根目录用既有静态服务打开同一路径（例如 `python3 -m http.server 8000`）。本轮导出/验证使用仓库现有Chrome/CDP离线方式。

- 左：原70%基准，保留原shoulderCover。
- 右：既有base与字迹 → 原有活动前肢/手爪/铅笔 → 新前景RGBA，替换旧shoulderCover。**同一PNG始终按(0,0)原尺寸绘制**，无逐时遮罩、拟合、缩放或新几何变形。
- 默认没有素材，右边只有去掉旧shoulderCover后的底稿；空白模板不表示静态通过。尺寸错误或整张不透明的合成图会被拒绝。
- 每次加载先回t=0并取消前次确认。先看全图、200%局部、Alpha与棋盘：若有暗弧、双层毛纹、硬切口、亮度跳变、旧臂/背景残留或突兀遮挡，就停止，返回绘画工具修素材。
- **只有人工确认t=0后**，勾选确认框，才启用t=2.581、t=3.8和连续播放。三个时刻复用同一层；检查固定毛尖与活动臂的前后关系、有无错误盖住笔爪。连续播放可暂停；重载PNG会重新要求静态确认。

勾选只表示操作者的静态判断，预览不会自动判定审美合格。已有横向压缩应单独记录；它不自动否定静态毛发接合，静态接合通过也不表示完整动画已成功。

## 本轮验证与复现

已实际查看全景注册图、局部指引及空模板预览。verification.json记录空模板全透明、原参考逐通道一致、尺寸与全不透明图拒绝、重置、播放推进、三个时刻同层同坐标。注册探针只是内存里一个测试像素，没有写成候选图或当作毛发验收；尚未使用人工新素材进行视觉验收。

分层ORA已核对画布、层顺序/可见性及嵌入PNG与外部文件一致；此环境未安装Krita/GIMP，未实际在这两款编辑器中打开。它是标准OpenRaster文档，不包含软件专有的锁定或选中层状态，请打开后手动选择顶层并锁参考层。

仅在本目录写输出：`export-template.mjs`导出参考、标注、空层与预览截图，`package-template.py`封装ORA，`verify-preview.mjs`验证加载/坐标/控制。预览复用已有 scratch/shoulder-static-70/scene-study.js 的图层接口，不加载其失败修复study.js。依赖摘要见inputs.json；修改正式动画不在本轮范围。
