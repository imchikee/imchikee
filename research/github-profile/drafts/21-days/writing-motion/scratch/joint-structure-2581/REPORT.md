# S/E/W 关节结构单帧实验（右版 t=2.581s）

**结论：当前结构候选未通过。** 已画出明确肩—肘—腕关系，并据此形成连续轮廓，但实际合成中的肩端圆头、内侧收腰仍不自然。不能凭有骨架或遮罩清理成功宣布姿势可信。仅输出这一种结构，不继续扩大肘部或生成更多轮廓。未修改正式动画。

## 先建立关节，再生成包络

structure-annotated.png 先展示单一结构假设：

- S=(400,850)，固定肩参考。
- E=(435,880)，肘在肩的右下方，不向画面左侧膨胀出一个大肘盘。
- W=(506,860)，腕在原粉色手爪后方。W是推测的隐藏关节，不是从原画直接测到的骨点。
- 青线S→E为上臂，粉线E→W为前臂。上臂投影长约46.10px，前臂约73.76px；这些只是本次2D设计参数，没有声称是真实仓鼠骨长。
- 肩侧与腮毛相接处原腮轮廓在前；腕端粉爪/笔在前。草图用虚线腕圈及文字标明遮挡，骨线是透视式结构标注，不代表最终可见线条。

轮廓不由上一轮Bezier外形改点得到，也不用旧前肢位移公式。代码从S/E/W中心线出发：上臂直段、经过E附近的圆润二次曲线转弯、前臂直段；沿中心线取渐变半径截面包络，半径从25px过渡到肘部23px再到腕部17px，没有放大肘半径。二次曲线只用于连接骨架方向，非上一轮扁圆大块的外形路径。没有毛纹压缩，也没有任何运动插值。

## 保留的合成机制

沿用上轮已验证的clean-base清除与粉爪/笔保护机制：在当前真实基准与无活动肢体底层的差异区移除旧橙色前肢，再绘制新的独立Alpha Mask诊断颜色，最后还原原粉爪/笔像素。没有x=490.700015垂直截断。腮毛按原边界遮挡新肢体；腕端伸到粉爪后方。

附cleared-limb.png、old-limb-mask.png、contour-overlay.png以便检查清除和覆盖。新遮罩之外露出的旧前肢区域恢复为底层，检查到残留差异为0；保护区原像素变化为0。新遮罩超出旧提取区2053像素，其中922像素在实际候选中显示出改变。计数仅支持合成机制有效，不是自然度判据。手工粉爪保护边界仍带少量橙色旧毛边，不能将其称为完整干净的角色分层。

## 根据实际截图判断

- **肩部**：候选在S附近形成可见圆头，原腮毛没有把它充分遮住。S参考在y=850，而该处原腮下缘约在y=805附近；严格保持当前腮轮廓时，不能声称这个S已经藏在脸后。肩根的出肢方向未建立可信的身体连续性。
- **肘/前臂**：肘不再是上轮大扁圆盘，下缘能读到向下弯后向腕回升的结构。但内侧上缘在上臂与前臂交汇处形成明显收口，肩端鼓、腕前较细，仍有“弯管/收腰”的感觉。连续截面生成并未自动带来可信解剖。
- **握笔/遮挡**：原粉爪稳定盖住W及新腕部，笔尖和握姿不动；但原毛边与纯色草案交接仍可辨，未证明最终自然连接。
- **体积/透视**：本次长度来自两段中心线的折向，不是横向纹理挤压；但没有三维深度参考说明上臂如何绕出身体、肘如何位于身体前方，故不能仅凭折线比端点直线长判断缩短问题已解决。
- **非目标区**：没有重绘头、眼、帽子、背景。新肢体局部遮挡纸页属于草案遮挡变化，纸页本身未重绘。所有变化仍在局部实验范围内。

## 具体冲突与证据边界

当前选择的S/E/W排布让上臂先向右下、前臂再向右上；在保留腮轮廓和粉爪位置时，要表现这一转折，内侧空间有限。减小截面会形成细腰，增大截面则容易回到上轮宽块。当前包络未能解决这一结构/厚度矛盾，因此失败。

这不是证明固定端点必然无解。隐藏的真实肩关节位置、上臂出肢方向和深度并没有现成参考；本轮只是一个明确的2D假设。没有足够证据证明可在当前参考下建立可信前肢，不能继续强行宣布通过。
