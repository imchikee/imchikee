# 保守腕部动作：一次候选未达到“整体更自然”

基准commit：4d75cf568d28e6e2ca44130eb1c00d739a971cae。**前臂横向纹理挤压减少，但腕部滑接、细缝和抬笔折接新增缺陷，暂不能用作更自然的替代。** 本轮仅一个候选，没有改参数后再试。

## 唯一改动

70%基准中的前臂，原来从x=400到515通过同一位移场同时承接横向dx、纵向dy。候选改为：

- 前臂所有横坐标保持不变；x≤450的主体保持原坐标，x=450–515的末端只用平滑位移场承接原dy，形成65px纵向过渡。未添加新遮罩、羽化或补底。
- 已有gripWorld（含粉色手爪、笔及少量相邻橙色臂纹）继续按**原70%目标dx/dy刚性平移**，无旋转、无缩放；保持同一握笔关系，笔杆不会逐渐转竖。
- 墨迹、各笔画时序、提笔间隙、最终抬笔路径全部保留70%版本。候选没有靠缩小字形或文字自动出现来稳定前臂。

这是“前臂主体稳定、腕端相对运动”的一次直接检验，不是新的毛发方案。已有armPath、素材裁界、shoulderCover、头胸、眼神、书页和场景保持。第一幕和正式动画均未改。毛发路线仍停止。

**画面观察：**

- 起笔时与基准一致，原肩部静态斜缝仍在，未处理毛发。
- 书写前中段，近肩和大部分前臂毛纹不再向手爪挤拢，这是实际收益。但手爪层左沿在固定臂面上滑动；局部采样约1秒可见细竖缝，整段也可见分层交界变化。
- **2.581秒**：前臂主体较稳定，手爪向左覆盖其末端，腕部更像移动图层搭在固定臂上；橙色毛纹在交接处滑接，不能据没有整体缩短就认为连接自然。
- **3.8秒及收尾**：笔与爪有明确上提，笔角不变；但前臂末端被斜向提起，叠在其上的刚性握笔层出现轮廓转折/台阶，抬笔自然度仍不过关。没有整个前臂均匀变细，新增问题主要集中在腕端交界。

已有armWorld截到x=515，gripWorld的橙色部分从x≈514起。候选不再把前臂末端随dx送过去，二者的裁界因此不一致：按裁界估算，左移最多约18px搭接，向右的小行程最多约0.55px间隙（未计栅格抗锯齿）。前者导致原臂纹理相互覆盖/滑动，后者能露细缝。纵向过渡还加大局部剪切。这是当前素材与分层对该候选的实际限制，不能靠盖一层毛发、增加遮罩或强拉纹理掩盖。

## 字迹、握笔与抬笔

保留完整六段i++笔画及笔间抬起：笔尖目标和墨迹使用同一个70%映射与同一时钟，没有另一个文字淡入/打字动画。粉爪与笔在同一刚性层，内部关系不变，笔轴旋转为0。

i的点/干和两个加号仍可辨；字形大小、位置与上一轮70%相同。可参照既有 [70%隔离字迹](../amplitude-2581/ink-0.7.png)。全景里字迹仍小、朝向角色，不能把放大图可辨称作正常尺寸一眼清晰。本次没有新增可读性损失，也没有以50%或更小字迹换取稳定。

最终笔尖最大上移约16.7场景px，画面能读出离纸意图；候选爪/笔与基准完全同路。不过腕端连接的转折使“自然抬笔”仍未达标。报告的跟踪数值比较几何目标与墨迹，不是对绘画中笔尖像素做检测。

## 结论与交付边界

**未满足成功标准，不建议替换70%基准或接入正式动画。** 取消整臂横向挤压并没有带来整体更自然：问题集中到了腕部的滑接、细缝与抬笔折接。当前已分开的静态前臂与刚性握笔素材，不能直接支持本候选所需的相对移动连接；本轮不继续遮盖或拉伸修补，也不据单一失败断言所有保守书写方案都无解。

已实际查看基准/候选六时刻局部采样、两张精确时刻对照，以及候选MP4每约1/3秒的解码采样。三个MP4完整解码通过，均30fps、147帧、4.900秒；同步对照两侧在同一视频里逐帧配对。视频最后一帧为4.8667秒，精确4.89875秒另存PNG，收尾姿态相同。头部、书页等素材摘要保存在inputs.json。

export.mjs只导出本目录同一个候选和原基准；render-review.mjs仅拼接已有PNG。所有实验输出在本scratch，未修改正式动画和第一幕。无新抠图、补毛、生成图或连接遮罩。完成提交推送后停止等待验收。
