# 右版 2.581 秒：单帧局部重绘实验

结论：本候选尚未达到验收标准。局部重绘可以改变毛纹和饱满感，但本次没有充分消除前肢短粗、挤压的视觉感受。等待人工验收，不接入动画。

## 输入及方法

检查了 forelimb-static-v33.png、scene-motion-study.js、sketch-motion.js、motion-comparison-after.html 及关联的场景/头胸/书页图层代码。基准从现有右版真实运行并调用 sketchMotion.render(2.581) 导出，等待两次 requestAnimationFrame。完整 pose 记录见 pose.json。

- draft 笔尖：约 (639.400025,999.503783)。
- 场景笔尖：约 (587.700015,895.087688)，contact=true。
- 源码肩参考：(400,850)。
- 当前刚性手爪层起始边界：x=515，加当前位移后为 x=490.700015。

选择内置 imagegen 局部重绘，而非等弧长或 smoothstep 形变。以基准全景作为编辑目标，要求只重画橙色前肢及肩部过渡；PROMPT.txt 保存完整提示词，repaint-source.png 保存未合成的生成结果。

生成图不能保证非目标区域逐像素不变，所以没有整体采用。compose.html 只将绘制区域局限于肩下橙色前肢，沿既有腮部边界裁切，边缘2px过渡；从x=490.700015开始的手爪/铅笔区域完全保留基准像素，其他场景仍来自基准。轮廓路径仅用于取出实际重绘毛发，不以几何色块冒充肢体。没有对手臂使用空间形变。

## 实际画面观察

| 项目 | 观察与判定 |
|---|---|
| 肩部连接 | 候选肩下新增较深的毛纹过渡，原先较直的分层感减弱；但边界仍可辨，局部亮度和毛色更亮，与固定肩毛不完全一致。不能判为连接已自然。 |
| 前肢厚度 | 候选毛发更饱满，不像原来压密的纹理；但外侧肩到握笔爪的可见跨度仍短，整体仍显短粗。没有解决本实验的核心缩短感。 |
| 轮廓连续性 | 相比基准没有新增明显窄腰或折角；本次改变主要在毛纹和内部明暗，上下缘构型变化有限，因此无法仅凭这一点认定修复有效。 |
| 握笔稳定性 | 候选保留基准粉爪、手指、笔杆和笔尖像素，实际图中握持关系相同，未见双笔或脱离。固定笔尖成立只证明约束保留，不证明前肢自然。 |
| 画风 | 温暖绘本毛发风格基本相近，但候选橙色区域更亮，近看有色调接合感。 |

## 限制及缺失内容

原素材只有一个完整前肢视角，缺少该落点下真实肩—肘—腕的转向与遮挡参考；隐藏在腮毛后的上臂结构也没有独立素材。本次生成未提供足够可信的新肘部构型，在锁定肩位和握笔爪后仍主要靠毛纹掩饰短粗关系，不能作为合格替代。

这不是证明“现有素材绝对无法修复”，也不是证明局部重绘能够解决。当前证据只支持：本次尝试在锁定目标约束后，尚未产出可信的单帧前肢姿势。未实现或推断整段动画效果。
