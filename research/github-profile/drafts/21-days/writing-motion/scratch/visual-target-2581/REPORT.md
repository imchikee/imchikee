## 为什么没有合成

本轮先看原始候选，未直接裁回图层。两张候选更顺的出肢都伴随肩侧/腮下遮挡边界变化。若先恢复原脸颊或原粉爪，可能再次产生未验证的连接断口；沿旧轮廓切回则会重复上一轮失败。因此没有用合成掩盖这个约束缺口，也没有交付“合成成功”结论。

## 哪项约束可能需要放宽

最直接需要人工决定的是：**肩部可见出口及与腮下毛发相交的一小段遮挡边界，是否允许共同重新设计。** 本轮较连贯的形态都动用了这段边界。若必须将其像素/轮廓完全固定，现有两张候选不足以继续。

这不是证明该边界必须改变，也不能证明当前姿势无解；只是本轮输出尚未给出受约束解。没有依据要求移动手爪、改变笔杆角度或笔尖目标，它们在本轮并未被单独验证为冲突来源。需要的是经人工认可的肩腮遮挡设计参考，而不是再猜一个S/E/W或继续精修毛发。
