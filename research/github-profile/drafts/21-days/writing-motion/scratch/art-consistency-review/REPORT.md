# 第一、二幕最终美术一致性审查

基准：`4705ed4b441bb8a7180a3026e2321dc4c7fb3eb1`。

**建议锁定第二幕，不再做最后一次美术修订。必须修改项：无。** 两幕有明确的绘制精细度差异，但在534px展示宽度下，我没有把切换读成更换角色或进入另一种画风。不是严格模型表一致，也不需要为了这种一致性重画当前可用画面。

[对照图](comparison.png) 上排是相同显示尺寸的完整实际输出，下排依次比较脸腮、毛发、帽子、灯光及环境。最重要的三项判断如下。

1. **脸型与帽子比例——可以接受；不建议修脸或帽。** 第二幕帽冠更高、帽子相对头部更大，脸部显得更收拢；第一幕腮帮横向体积更突出。这包含真实的造型偏差，不能全解释成俯视或灯位变化。但第二幕仍保留宽圆腮、短口鼻、小粉鼻、近距离门牙与拼色绿帽，没有长吻、尖下巴或五官位置失控。第一幕低头帧也有棕色眼部层次、小嘴和较收敛的表情，因此不能仅以第一幕抬头首帧的大黑眼睛、张嘴表情判定角色不一致。正常尺寸最先读到的仍是同一只仓鼠换成伏案姿势。为压平帽冠或重排五官而重画，收益不足以承担外观漂移风险。
2. **毛发与上色——可以接受；不建议重做材质。** 第一幕毛纹分组更简练，橙白边界的明暗分区更鲜明，轮廓更有线描感；第二幕细毛更密、腮边更绵软，橙白过渡更连续，整体更有体积塑造。两者都保留顺着脸腮生长的短毛与零散毛尖，并非一幕光滑塑料、另一幕写实长毛。第一幕橙色和粉爪更亮、更饱和，第二幕橙色偏蜜糖、白毛偏暖奶油、粉爪较柔和；色相身份仍稳定。放大对照能看出渲染差别，534px全景下不足以形成割裂。不建议用新增毛发或全图调色追齐。
3. **光照与环境——可以接受；不建议统一成相同灯效。** 第一幕有更明显的黄色光束、亮边和较深的书本轮廓；第二幕灯光扩散更柔，阴影偏棕、绿帽更沉，书页、杯子与木纹更细。第二幕书更多、角色占画面较小，细节密度更高，这是构图差异，未通过缩小角色来人为掩盖。两幕共同保留暖木色、奶油纸面、深绿灯帽、蓝红书脊和粗黑手写标题；墙面、桌面及书本都有可见绘画纹理。它们像同一绘本中两张精细度略异的画面，未达到必须重做背景或灯光的程度。

最终决定：**第二幕值得锁定，不值得再开一次美术修订。** 保留“帽冠比例略异、第二幕材质更细密”这两项已知差异即可。这是本轮审美建议，尚不代表人工验收或正式发布。
