# 仓鼠写字前肢：现有两版视觉诊断

本轮只读取现有 motion-comparison.html 和两个子页面。新增 capture-visual-diagnosis.mjs 及本目录诊断输出，没有修改动画源码、页面或图片素材。既有工作区修改不属于本轮。

[打开人工检查图集](index.html)。左侧是现有原版，右侧是取消额外上拱的候选。各时间均包含两版完整场景、前肢 200% 局部以及原对比网页截图。

## 截图与时间同步

使用已有 Chrome/CDP 自动化方式运行原对比页。每次调用 window.motionCompare.draw(t)，确认两个子页面内部 time 与目标时间一致，再等待各自两次 requestAnimationFrame，随后从实际渲染 canvas 导出对照，并截取网页。captures.json 记录每次两侧时间、画布尺寸及文件名。没有补画或重建角色。

完整图每侧保留 1316×1195 像素；局部取原场景 x=350、y=750、宽330、高220，放大到每侧660×440（200%，浏览器默认插值）。图集中的适应窗口显示会缩小大图，点击原图可按真实像素检查。

已截取 0、1、2、2.95、3.8、4.89875 秒，额外截取 2.581 秒。pose(t) 以 0.001 秒步长扫描，按笔尖水平位移找出候选肩端固定时横向压缩最大的代理时刻：2.581 秒、水平位移约 -24.300 px。这不是通过像素测量证明的“所有视觉缺陷最严重时刻”，也不代表原版曲线的视觉最坏点；仅用来补充取样。

## 五项诊断

- **肩部连接**：两版外侧肩毛位置大体固定，未看到整条肩根明显横滑；但固定腮毛/肩毛与活动前臂的边界仍可辨，尤其左版中后段弯曲后更像从固定毛块下接出一段变形肢体。不能据“肩点不动”判断连接自然。
- **前臂厚度**：左版中后段不是整体均匀变细，而是上下轮廓一起弯折，局部出现窄腰、另一段鼓起。右版保留较连续的上下缘，但相对0秒明显收短、显得短粗。仅凭这些截图不能推导真实三维体积或准确厚度损失百分比。
- **轮廓折角**：最显著差异是左版2秒以后出现上拱峰和下缘凹口，右版减弱了这种轮廓。右版的改善并未消除纵向挤压感。
- **手爪握笔**：所取时刻两版都能看到手指包着同一根笔，没有明显双笔、笔脱离爪子或握点突然断开。手爪与笔的内部关系几乎不变，握笔本身不是这组图中最突出的缺陷；这也不足以证明完整动作自然。
- **抬笔动作**：从2.95到3.8秒，两版手爪、笔尖一起向上移动，笔仍保持近似相同斜角。与书写终点相比能读出抬起意图，但单张图没有清楚的接触阴影/深度线索，不能精确判断笔尖离纸高度。手腕朝向几乎不变，变化主要由前臂形变承担；左版拱曲、右版收短因此延续到结束。

## 最不自然的三个检查时间

这是对本轮实际截图的人工判断，不是数学误差排名；没有宣称穷尽整段的所有坏帧。

1. **2.581秒**：左版前臂上下缘形成明显弯钩与窄腰；右版虽顺滑，但相对起笔最显收短。两种失败方式在同一时刻都很清楚。
2. **3.8秒**：抬笔后左版下缘凹口仍很深，右版前臂被提起收拢；固定肩部与活动爪子的关系显得僵硬，且该姿态延续到结尾。
3. **2.95秒**：左版接近收笔时仍出现不自然的波浪轮廓；右版保留短粗挤压感。可与3.8秒并排检查收笔到抬笔的变化。

4.89875秒与3.8秒姿态高度接近，因此没有作为第三个独立问题重复排名。0秒也存在接缝/分层感，说明问题并非全部由后续运动产生。

本轮到此结束，只交付诊断；没有实现修复。
