# v46：保持两段臂长，并去掉腕根硬接边

2026-11-06。用户反馈起笔/后段两张截图：手越写越短，腕根上方红框仍没处理干净。截图保留为feedback-v45-shortening-start.png、feedback-v45-hard-patch.png。

## 原因与处理

v45固定肩根后，以网格权重把整段手臂压缩到手的新位置，根部虽不漂移，毛臂仍会越写越短；腕根附近的源图切片上边界也暴露成色块。因此本轮不用网格压缩和三角片边缘修补。

从同一scene-v38-current.png拆出上臂、前臂、肘部重叠和手腕/爪笔素材。上臂/前臂都只做平移和旋转，绘制不使用任何缩放；肩部固定，肘关节按两段原长度求位置。增加适量转腕分担笔尖向左书写的位移，避免把全部变化压到肘部外摆，或把整只手大幅抬起。圆形毛腕与粉爪在同一刚性层里转动，笔与爪保持原相对位置；身体原画遮挡肩部接缝。笔尖及字迹仍共享原纸面落点。

内部先看了大幅屈肘候选，肘部外摆过大，保留为shot-v46-large-elbow-rejected.js；固定肘部只转腕的检查稿使手抬得过多，保留为shot-v46-fixed-elbow-check.js。最终分配到较小屈肘和转腕。毛腕最初上缘太高、像翻起的套口，已收成短圆形重叠，不把毛块贴到脸上。原v45源码/GIF及全部旧图保留。

本轮不新增生图，原画脸/表情/场景保持v38，不改变纸页方向、八笔代码和第一幕。固定预览在内部检查完成前仍为v45，候选仅通过render.mjs --shot=shot-candidate-v46.js导出，不新增编号HTML。

检查和最终接入状态后续按实际结果续记；不能将转动绘制的长度保持直接等同于用户视觉认可。
