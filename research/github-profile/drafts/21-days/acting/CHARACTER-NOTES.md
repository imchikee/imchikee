# 原头像的造型观察

用户要求研究自己的头像为何可爱。原头像：[avatar.png](../../personal-corner/assets/avatar.png)，工作区实际路径为`research/github-profile/drafts/personal-corner/assets/avatar.png`。以下是对画面的观察与助手的审美判断，不是普遍的心理学结论，也不等于用户已选择完全复制头像画风。

- 主体是一大团白色形状。鼓腮与身体连成柔软、不完全对称的轮廓，没有独立大头接梨形躯干的结构。
- 眼睛、嘴很小且集中在上方棕色面部区域；大面积白色留空与小表情形成比例反差。可爱不依赖放大黑亮眼球、眼镜或突出门牙。
- 手脚仅以很小的形状和短线交代，动作明确但不强调人的肩、肘、髋、膝和脚趾。画出完整拟人腿脚反而可能破坏原头像的简洁。
- 棕色粗线转折圆钝，有手画的不规则；外缘没有连续毛刺。主体以白、浅米和棕色为主，毛发细节很少。
- 跑动姿态、速度线与“紧急下班”情境让圆团子有行动性，略显笨拙；这也是头像趣味的一部分，不能仅提炼成静态站立吉祥物。

前稿偏离：大亮眼、黑色粗眼镜、密集毛发、锯齿外缘、分段头身和清晰人形四肢。用户还明确指出拼接缺口、握瓶不自然和内八字脚不好看。11秒拼接试段不采用为合格视觉基线。

下一版建议先检验“大白团子＋小而集中的表情＋极简小爪＋圆钝线条”，通过姿态和轮廓变化表现动作。帽子、眼镜和药瓶属于剧情道具，不应占据造型重心。此为基于观察的建议，尚未作为已确认新风格或完整动画实现。
