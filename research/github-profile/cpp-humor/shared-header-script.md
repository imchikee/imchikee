## 一句话

## 三个节拍

1. 仓鼠在公共头文件common.hpp的注释里改正一个错别字，轻松地说「就一个字。」
2. 保存后，屏幕突然刷出「Rebuilding 3,000 files」。仓鼠准备离开的动作停住。
3. 它慢慢坐回去。椰树/季节可以作为后续等待的夸张，但主包袱已经落在「没有改变程序逻辑的一处小改动，触发大范围重编译」。
