# Profile visuals

- The banner, engineering/interests cards, and Shell terminal icon are original SVG artwork for this profile.
- The animated introduction is generated with [DenverCoder1/readme-typing-svg](https://github.com/DenverCoder1/readme-typing-svg).
- The small technology icons are from [Devicon](https://github.com/devicons/devicon), used with visible text labels. A copy of the upstream license is in [`assets/icons/DEVICON-LICENSE`](assets/icons/DEVICON-LICENSE).
- The contribution animation is generated with [Platane/snk](https://github.com/Platane/snk) from this account's GitHub contribution graph.

The typing SVG is stored in this repository. To regenerate it:

```sh
curl --fail --location 'https://readme-typing-svg.demolab.com?font=Fira+Code&weight=500&size=21&duration=2800&pause=1400&color=82DDC5&center=true&vCenter=true&width=520&height=46&lines=Systems+software+%26+architecture;C%2FC%2B%2B+%C2%B7+Linux%2FQNX;Linux+%26+developer+tools' --output assets/typing.svg
```

The contribution animation updates daily through GitHub Actions and can also be regenerated with the workflow's manual trigger.
